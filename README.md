## Selected projects

### [HKD — Programming Language](https://github.com/HassanDev-git/HKD)

A statically typed systems language and developer platform. The project explores deterministic compilation, an SSA-based compiler pipeline, a stack VM, and a native Zig runtime.

### [HK-Ai — AI Workspace](https://github.com/HassanDev-git/HK-Ai)

A React, Vite, Express, and Socket.IO workspace with Firebase authentication. It brings together AI chat, model discovery, research, user-managed provider connections, and an optional WhatsApp bridge.

### [What Should I Eat? — Recipe Discovery](https://github.com/HassanDev-git/What-Should-Eat-Website-Design)

A responsive recipe discovery experience that turns ingredients on hand into meal ideas. Built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

### [LUMIERE — E-commerce Experience](https://github.com/HassanDev-git/Lumiere-E-commerce)

A luxury fashion storefront with responsive layouts, dark mode, product browsing, search, cart, wishlist, and checkout flows.
